Start with Impian 0.3.0

I'm the possibility of my dream

  1. Extract the Windows ZIP into its own folder and open Impian.exe. Keep the files together. Your existing planner stays in Windows' LocalAppData folder when you upgrade.
  2. Open Settings → Appearance. Sage green is the default, with ten alternatives.
  3. Follow Season → Goals & Tasks → Calendar → Focus. No account is required for local planning.
  4. Read the user guide and FAQ. Their included HTML copies open in your browser and work offline.

Optional connections

  • ChatGPT: Settings → AI with your ChatGPT account → Continue with ChatGPT. Eligible accounts can power text planning using their plan limits. Live sign-in and inference remain unverified. Old conversations are not imported. Voice transcription uses the separately selected API-key option.
  • Impian login: Google, Apple and email integration is built. App-owner service configuration is intentionally deferred, as requested. The planner works while setup is pending.
  • Google backup: configure the app's Google registration, connect your own account and choose manual, weekly or monthly backup. Optional scheduling can run while Impian is closed and you are signed into Windows. Restore through Impian's backup browser.
  • Google/Outlook calendars: separate calendar connections; see calendar setup. Test on a spare calendar first. Live two-way sync and remote undo remain unverified.

App-owner instructions and live acceptance steps are in connection setup. Never paste passwords, tokens or API keys into chat or GitHub.

Focus and undo

Windows app blocking closes selected exact-path applications after consent for each focus session. Save work first. Pause focus, use the tray's Emergency release, or press Ctrl+Alt+Shift+F12 to release enforcement. See Windows blocking.

Undo preserves unrelated work and history. Reversals of published calendar changes require a preview, enter the durable queue and are checked against the server version. A conflict stops publication.

Branding

Concept 08 — Steady Progress, the infinity-shaped mark with a gold dot, is applied to the sidebar, executable, window and tray. The default appearance remains warm off-white, sage, forest and charcoal. See the brand guide.
