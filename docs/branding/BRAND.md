# Impian — selected concept 08: Steady Progress

The logo is an infinity-shaped line with a warm gold dot, representing steady progress toward a dream. The wordmark is lowercase **impian** in Segoe UI Semibold.

The exact tagline is **I'm the possibility of my dream**.

## Default appearance

Sage green remains the default: warm off-white canvas, sage highlights, forest buttons, charcoal text and a gold logo accent. Dark appearance uses forest and grey-green surfaces.

- Primary forest: `#293B32`.
- Gold dot: `#B99450`.
- Warm white: `#FAFAF8`.
- Sage calendar tint: `#DDEADD`.

## Ten additional choices

Settings → Appearance offers Electric Iris, Cobalt & Coral, Tropical Spark, Tangerine Sunset, Midnight Pop, Dusty Lilac, Soft Slate Blue, Terracotta & Cream, Dusty Rose, and Honey & Oat. Midnight Pop always uses dark surfaces. The others also support dark appearance. The sidebar mark follows the chosen theme; the Windows icon retains the forest background.

## Assets

The `selected` folder contains transparent SVG and PNG versions, an app tile, Windows ICO and preview. Some filenames retain the old `monogram` label for compatibility; their artwork is now concept 08. ICO frames include 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels.

Production assets are embedded from `src/Impian.Desktop/Assets`. `scripts/Build-Brand.mjs` regenerates them with the optional Sharp development library. Ordinary builds use the supplied images.
